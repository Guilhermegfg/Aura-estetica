# Aura Estética

Landing page fictícia de demonstração para uma clínica de estética premium.

## Objetivo

Apresentar procedimentos, equipe, resultados e avaliações com foco em conversão para agendamentos via WhatsApp.

## Identidade visual

- Principal: `#5C4650`
- Secundária: `#FFF9F7`
- Destaque: `#D8B4A0`
- Tipografia: Cormorant Garamond + Manrope

## Recursos

- Layout responsivo e mobile-first
- Hero com CTA de agendamento
- Cards de procedimentos
- Seção de profissionais
- Prova social e avaliações
- Botão flutuante do WhatsApp
- Instagram
- SEO local básico
- Schema.org do tipo BeautySalon
- Animações leves por IntersectionObserver
